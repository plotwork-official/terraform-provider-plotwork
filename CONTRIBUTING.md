# Contributing

## Set up

| Tool | Version |
|---|---|
| Go | the version in `go.mod` |
| Terraform or OpenTofu | 1.9 or later, on `PATH` |
| golangci-lint | v2 |

```shell
make          # format, lint, test, build
make generate # rewrite docs/ from the schema, templates/ and examples/
```

## Layout

| Path | What it is |
|---|---|
| `main.go` | Serves the provider over the plugin protocol |
| `internal/client` | The HTTP client for the Plotwork API: retries, the error envelope |
| `internal/provider` | The provider, data sources and resource, on the Terraform Plugin Framework |
| `internal/provider/fake_api_test.go` | An in-memory Plotwork API the tests run against |
| `examples/` | Terraform the docs embed; `examples/complete` is a whole stack |
| `templates/` | The docs' hand-written parts |
| `docs/` | Generated by `make generate`. Do not edit by hand |

## Rules

| Rule | Why |
|---|---|
| Every exported name and every schema attribute has a description | The registry docs are generated from them |
| API failures go through `addAPIError` | It adds what a Terraform user can do about each error code |
| A test for each behaviour, against the fake API | The tests need no account and no network |
| `make generate` after a schema change, and commit `docs/` | CI fails on drift |
| Conventional Commits (`feat:`, `fix:`, `docs:`) | The changelog is written from them |

## Try a local build in Terraform

```shell
go install .
cat > ~/.terraformrc <<EOF
provider_installation {
  dev_overrides { "plotwork-official/plotwork" = "$(go env GOPATH)/bin" }
  direct {}
}
EOF
```
